# 🌸 View My Projects

**Projeto 1 — Lançador de Projetos p5.js**
Unidade curricular: Edições Multimédia Interativas · LEM 3 · ISTEC Porto · 2025/2026

---

## Descrição

Página web interativa que serve de portal de navegação para os projetos desenvolvidos em p5.js. Apresenta dois projetos em formato de cartões clicáveis (*RedCircle* e *BlueSquare*), cada um com pré-visualização e ligação direta à respetiva demo no GitHub Pages.

## Demo

🔗 [vero279.github.io/ViewMyProjects](https://vero279.github.io/ViewMyProjects/)

## Funcionalidades

- Galeria de cartões interativos com pré-visualização dos projetos
- Barra de pesquisa para filtrar projetos por nome
- Cada cartão abre a demo do projeto ao ser clicado
- Alojamento via GitHub Pages

## Tecnologias

| Tecnologia | Função |
|---|---|
| p5.js | Motor gráfico e lógica interativa |
| HTML5 | Estrutura da página |
| CSS3 | Estilização e layout responsivo |
| JavaScript | Lógica da UI e interações |
